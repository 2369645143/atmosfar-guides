## 手持 Extractor 处理不了的大型废料

Cloud Cruiser 日志描述了超出手持 Extractor 处理能力的废料。其回收流程是用 Cargo Wasp 运回母舰，在自行建造的材料处理器外侧入口投放，再进行处理。[处理器来源](https://www.atmosfar.game/feed/dev-blog-10-cloud-cruiser-101)。

这需要先拥有 Cargo Wasp 和适用的母舰设施。开发者明确说明 Cloud Cruiser 未包含在 Steam 新品节 Demo 中，因此这不是 Demo 解锁路线。[Demo 范围来源](https://www.atmosfar.game/feed/dev-blog-15-cloud-cruising-to-early-access)。

## 先理解吊机能做什么

Wasp 日志描述了耗电的磁力吊机：缆绳可伸缩，磁铁可吸附和释放物体。Cargo Wasp 速度慢，燃料与维护成本较高，操作重点是精确，而不是高速。[Wasp 来源](https://www.atmosfar.game/feed/dev-blog-5-wasps-101)。

更早的 Cargo 日志也描述了吊运无法就地拆解的废料。它可以佐证吊运用途，但早期货梯布局不能直接当作当前建造图纸。[早期设计背景](https://www.atmosfar.game/feed/dev-blog-2-up-in-the-atmosfar)。

## 按这个顺序规划任务

以下是编辑整理的工作顺序，不是已经实测的按键教程：

1. 确认当前版本允许吊起的目标，以及准备送达的位置。
2. 先准备接收区域和所需设备，再去取货。
3. 查看载具损伤、燃料、吊机电力和返程路线。
4. 按画面的吊机提示操作，建立稳定接近姿态后再吸附。
5. 低速运输，对准接收区域，看清位置后再释放。
6. 检查处理器产物与可用储存空间，再安排下一趟。

| 问题 | 重试前先检查 |
| --- | --- |
| 磁铁不吸附 | 当前交互提示、电力、目标是否可吊运 |
| 无法投放 | 接收设备与接近空间 |
| 处理未启动 | 当前版本显示的模块要求与输入条件 |

以上排查是编辑建议，不代表所有故障的确定原因。本文不推断载重上限、缆绳长度、油耗或固定按键。
